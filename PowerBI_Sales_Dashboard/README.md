# Power BI Sales Dashboard

## Project Overview
This dashboard analyzes sales performance across provincess, channels, and account types.

## Objectives
- Track revenue trends
- Identify top-performing branches
- Monitor regional sales performance

## Tools Used
- Power BI
- Excel
- DAX
- Power Query


## Key Insights
- Limpopo generated the highest revenue.
- The Youth account type brings in the most money.
- March 2026 recorded peak transaction performance.
